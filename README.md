# Horario Visual — Ellucian Banner (Santo Tomás)

Aplicación web 100% estática (sin servidor ni contraseñas) que transforma el horario de **Ellucian Banner Self-Service** (*Horario de Detalle de Alumno* y *Semana de un Vistazo*) en un calendario semanal visual, limpio y exportable.

## Características
- **3 formas de importar**:
  1. Subir uno o varios archivos `.html` guardados (`Ctrl + S` -> *Solo HTML*), combinando cursos automáticamente por NRC.
  2. Copiar y pegar texto (`Ctrl + A` / `Ctrl + C`).
  3. **Bookmarklet 1-clic** desde *Semana de un Vistazo* en Banner.
- **Grilla universitaria por bloques** (bloques de 40 minutos con recreos).
- **Salas y pisos limpios** (ej. `Sala 11 · Piso 5`, `Lab 02 · Piso 6`).
- **Manejo de topones** (bloques lado a lado en la grilla y en el PNG).
- **Exportación local**: PNG de alta resolución, PDF (impresión) y `.ics` para Google Calendar / Outlook / Apple Calendar.

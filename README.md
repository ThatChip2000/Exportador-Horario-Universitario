# Horario Visual — Ellucian Banner (Santo Tomás)

🌐 **Abrir la Web App:** **https://thatchip2000.github.io/horario-visual-banner/**

Aplicación web 100% estática (sin servidor ni contraseñas) que transforma el horario de **Ellucian Banner Self-Service** (*Horario de Detalle de Alumno* y *Semana de un Vistazo*) en un calendario semanal visual, limpio y exportable.

## Cómo usarla en 1 clic
1. Entra a **[Horario Visual](https://thatchip2000.github.io/horario-visual-banner/)**.
2. Haz clic en **Importar de Banner → 🔖 Bookmarklet** y arrastra el botón **📅 Abrir en Horario Visual** a tu barra de favoritos.
3. Inicia sesión en el portal de Santo Tomás, abre **Semana de un Vistazo** y haz clic en tu marcador: tu horario se cargará automáticamente con nombres reales, salas/pisos y profesores.

*(También puedes subir archivos `.html` guardados con `Ctrl + S` o pegar el texto con `Ctrl + A` / `Ctrl + C`.)*

## Características
- **Grilla universitaria por bloques** (bloques académicos de 40 minutos con recreos).
- **Salas y pisos limpios** (ej. `Sala 11 · Piso 5`, `Lab 02 · Piso 6`).
- **Manejo de topones** (bloques lado a lado en la grilla y en el PNG).
- **Personalización**: colores por ramo, tema oscuro/claro, unir bloques consecutivos y marcar hora actual.
- **Exportación local**: PNG de alta resolución, PDF (impresión) y `.ics` para Google Calendar / Outlook / Apple Calendar.
